# 黄昏庭 · 细体素日式庭院微缩景观 — 架构分析与实现方案

## 1. 现有项目架构分析

| 部分 | 现状 |
| --- | --- |
| `web/index.html` | OPUS 音游本体：单文件（约 400 KB）HTML5 页面，6 段内联 `<script>`，全部 Canvas2D 绘制（`drawBack` / `drawField` / `drawNotes` …），无模块、无构建、无第三方依赖。 |
| `web/sw.js` | Service Worker，`CORE` 预缓存游戏页；其余同源 GET 请求 cache-first 并运行时缓存。 |
| `web/_headers`、`manifest.webmanifest` | 静态托管头与 PWA 配置。 |
| `desktop/` | Electron 外壳，通过 `opus://app/OPUS.html` 加载打包后的单文件游戏。 |
| 测试 / 类型检查 / 构建 | 仓库内 **均不存在**（无 package.json、无测试、无 CI）。运行方式为 `cd web && python -m http.server 8080`。 |

**与任务的矛盾**：OPUS 是 2D 下落式音游，没有任何地图、场景、相机、3D 或体素系统；“适配项目相机/查看方式”在本仓库没有可复用的对象。
为不替代产品、不改动原功能，本实现采取 **纯增量、隔离** 的方式：

* 新增独立页面 `web/garden/`（与游戏同属 `web/` 静态站点，可随 `web/` 一起部署），沿用项目“零依赖、静态托管、浏览器直接运行”的技术路线：原生 WebGL2 + 原生 ES Module，无打包步骤。
* **不修改** `web/index.html`、`web/sw.js`、`desktop/` 的任何代码；视觉风格（Georgia 衬线字体、金色 `#f2b46d` 强调色、暗色半透明卡片）与 OPUS 菜单保持一致。
* 开发工具（单元测试、`checkJs` 类型检查、无头浏览器截图）放在仓库根 `package.json` / `tests/` / `tools/`，不进入 `web/` 部署目录。

## 2. 原云任务技术方案（设计目标，实际交付见第 6 节）

### 2.1 数据层（纯函数，可在 Node 中测试）
* `volume.js`：`VoxelVolume`（`Uint8Array` 调色板索引，256×176×128 ≈ 5.8M 格）及几何画笔（盒、椭球、圆柱、线段、圆盘）。
* `palette.js`：约 130 种材质；每种材质含 sRGB 颜色、逐体素色彩抖动、摇曳（风）、自发光、叶片透光、高光等标志。打包为 256×2 RGBA 纹理供着色器查询。
* `rng.js`：可复现的种子随机数 + 值噪声 / fBm，所有生成结果确定。
* `scene/*.js`：分模块的程序化建造器 —— 地形与溪池、木屋、拱桥、植物（垂樱、红枫、竹林、紫藤、花草蕨菇）、小品（石灯笼、蹲踞与竹筒、鸟居、茶桌、橘猫、纸鹤、望远镜）、围墙。
* `garden.js`：按构图组合全部建造器，输出体素体、点光源、锦鲤游动路径、粒子发射区、相机构图。
* `mesher.js`：按 32³ 分块的 **贪婪网格化（greedy meshing）+ 逐顶点环境光遮蔽（AO）**；只有材质与 4 角 AO 完全一致的面才合并，AO 各向异性翻转三角形对角线。顶点 8 字节（`u16 x,y,z` + `u16 材质|法线|AO`），水面单独成网格。

### 2.2 渲染层（WebGL2）
1. **天空**：全屏着色器 —— 落日渐变、太阳与光晕、条状晚霞、三层“阶梯量化”的雾蓝群山剪影（呼应体素语言）、下方云海。
2. **阴影**：低角度暖金夕阳的正交阴影贴图（高画质 4096²），硬件比较 + 多点 PCF。
3. **不透明体素**（4× MSAA HDR 目标）：太阳漫反射 × 阴影 + 天空/地面半球环境光 × AO + 最多 16 个点光源（灯笼、门廊灯、纸窗）+ 叶片背光透射 + 逐体素颜色抖动 + 细微体素边缘描线（随距离淡出防摩尔纹）+ 树叶/紫藤风摆 + 距离雾。
4. **锦鲤**：小体素模型，逐帧模型矩阵 + 顶点着色器摆尾，绘制在水下。
5. **水面**：解析一次 MSAA → 复制颜色/深度纹理，水面着色器采样做折射、按水深着色（冷蓝青）、菲涅尔天空反射、太阳高光、岸边泡沫、沿溪流方向的流纹。
6. **粒子**：樱花瓣、枫叶飘落，萤火与浮尘（加法混合）。
7. **后期**：半分辨率高斯模糊链 → 泛光 + **移轴（tilt-shift）景深**（微缩景观质感）+ ACES 色调映射 + 冷暖分离调色 + 暗角 + 细颗粒。

### 2.3 交互与相机
近似等距的小视场角（约 24°）透视轨道相机：拖拽旋转、滚轮/双指缩放、右键/Shift/双指平移、键盘（WASD 平移，Q/E 旋转，R 复位，空格自动环绕，H 隐藏界面，P 截图），带阻尼；画质三档（自动检测）。

### 2.4 性能
* 生成与网格化在 **模块 Web Worker** 中进行（不支持时回退主线程），分块网格以 Transferable 传回。
* 贪婪合并 + 面剔除 + 分块视锥剔除；水面与不透明分离；后期在半分辨率进行。
* 画质档位控制 MSAA、阴影分辨率、像素比与后期。

## 3. 分阶段执行
1. 阶段一：基础设施 —— 体素体、调色板、随机/噪声、网格化器及单元测试。
2. 阶段二：渲染管线 —— 相机、天空、阴影、体素着色、水、后期，用测试场景验证。
3. 阶段三：庭院内容 —— 按参考描述逐个建造构图元素，反复截图调整美术。
4. 阶段四：动态与交互 —— 锦鲤、粒子、风摆、灯光闪烁、UI 与画质档位。
5. 阶段五：验证 —— 单元测试、`tsc --checkJs` 类型检查、无头 Chrome 运行时截图与控制台错误检查；代码审查并修复。

## 6. 实际交付与代码审查

### 实现

- `scene/terrain.js`：分层切片地台、蜿蜒池水、苔藓石岸、石板步道、碎石水钵环道与瓦帽围墙。
- `scene/architecture.js`：木屋梁柱、逐格纸窗、瓦片与瓦脊、门帘、门廊暖灯、彩色纸鹤、茶桌茶具、橘猫、黄铜望远镜、弧形木桥、红鸟居、石灯笼和竹筒水钵。
- `scene/plants.js`：使用相关 3D 噪声打散树冠、悬垂樱花和紫藤、红枫、竹林、分组的蕨草/绣球/花菇、荷叶与落瓣。
- `worker.js`：后台生成与网格化、可转移二进制缓冲区；无 Worker 时主线程回退。
- `renderer.js` / `shaders.js`：WebGL2、紧凑整数顶点、贪婪网格、AO、2048² 静态 PCF 阴影、暖灯局部光照、自发光窗纸、逐体素明暗、晚霞天空与阶梯远山、透明动态水纹、7 条动态体素锦鲤、花瓣与萤火点粒子。使用浏览器原生 MSAA；没有宣称实现原设计中的 HDR 多级 bloom、景深、屏幕空间折射或逐帧阴影。
- `index.html` / `style.css` / `main.js`：独立 `/garden/` 页面，桌面与竖屏构图、轨道相机、鼠标/触控/键盘控制、画质像素比三档、暂停、自动环绕、PNG 留影、界面显隐、加载/错误说明、`prefers-reduced-motion` 默认暂停。
- `web/index.html`、`web/sw.js`、`desktop/` 没有修改。新增 README 入口和实机预览图。

### 审查发现并修复

1. 恢复的 `VoxelVolume.capsule` 细线分支未遵守 paint 返回 `-1` 跳过的约定，会写入 `Uint8Array` 为 255，导致非法调色板索引。已修复并加专门回归测试；整场景同时验证每个材质编号合法。
2. 实机 GLSL 编译发现 `sampler2DShadow` 缺少精度声明，补为 `highp`，Chrome 无着色器编译错误。
3. 首轮竖屏截图发现岛屿右侧裁切，调整小视场相机的竖屏 FOV 并重新截图。
4. 自动环绕状态在滚轮操作后未同步按钮；已同步。键盘连发会反复触发切换；仅连续运动保留重复，切换行为过滤 repeat；指针捕获丢失也清除拖拽状态。
5. 视觉审查发现平滑椭球树冠层纹过于规则、鸟居被竹林遮挡；以 3D 噪声和细簇打散树冠，并将鸟居前移，重新验证。
